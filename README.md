# Birthday Mix

Website statis mobile-first bertema aplikasi musik.

- Buka: `https://limah28.github.io/`
- Semua konten (password, nama, foto, surat, lagu, hadiah) diatur di `js/config.js`.
- Foto: taruh file di `assets/photos/`, lalu tulis path-nya di `config.js`.
- Musik: taruh `.mp3` di `assets/music/`, lalu isi kolom `src` di `config.js`.
